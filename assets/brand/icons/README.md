 # Fleet Maintenance icon system

These are transparent, standalone SVG icons derived from the supplied icon grids.

## Variants

- `dark/`: high-contrast variant for the navy sidebar and other dark surfaces.
- `light/`: high-contrast variant for white or pale surfaces.

Each file uses a `96x96` viewBox and contains no background or label, so it can be rendered with `<img>`, CSS or a Vue component.
